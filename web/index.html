LVS-Gateway

Lovense-compatible BLE gateway firmware for compatible LoveSpouse/MuSE toys, with an experimental multi-gateway dashboard.

Install firmware

Connect a compatible ESP32 or ESP32-S3 board over USB using Chrome or Edge. Firmware binaries and a valid manifest must be published with this page for the installer to work.

Gateway dashboard

Connect multiple gateways, send intensity commands per gateway, and stop connected gateways. Requires Web Bluetooth in Chrome or Edge on HTTPS.

Open dashboardSetup guide

Protocol limitation: commands to LoveSpouse/MuSE toys are broadcasts without a unique toy address. Multiple toys in range may respond, even when the dashboard controls different gateways independently. This does not guarantee physical 1-to-1 targeting.
