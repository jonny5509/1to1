Know what is actually paired

This dashboard sends commands to each connected gateway independently. The current LoveSpouse/MuSE protocol is a radio broadcast without a unique toy address, so every compatible toy in range may react. A label such as “Toy 1” is a note, not proof of physical-device isolation. True 1-to-1 control requires a supported addressing/channel mechanism or verified radio isolation.
